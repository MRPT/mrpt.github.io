# Images for docs.mrpt.org

Images referenced by absolute URL from the MRPT documentation
(https://docs.mrpt.org/), so they don't need to be stored in the main MRPT git
repository. Don't rename or overwrite files used by published docs: add a new
file name instead (e.g. with a `_v2` suffix).

- `apps/`: app screenshots (720 px wide WebP) for the apps gallery and app pages.
